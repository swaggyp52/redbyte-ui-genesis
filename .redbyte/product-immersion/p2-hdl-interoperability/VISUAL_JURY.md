# P2 Visual Jury

Visual/UX convergence + accessibility record for P2 surfaces (Source, filesets,
Import/Review, VCD Analyzer, constraint sets). Studio Light owns application surfaces;
dark instrument surfaces are limited to circuit canvas, waveform, and code viewer.

## Checklist per surface

- [ ] 1440×900 and 1366×768 without root-axis overflow.
- [ ] 200% zoom remains usable (no clipped controls, no overlap).
- [ ] Reduced-motion honored.
- [ ] Full keyboard operability (focus order, visible focus, no traps).
- [ ] Contrast within the Studio token system.
- [ ] Honest evidence-tier labels visible where results/artifacts are shown.
