# RedByte Agent Skills

These source-controlled skill prompts are the durable RedByte behavior layer for local agents, Codex, Copilot, and future Obsidian-backed workflows.

They are not generated outputs and they are not model training weights. They define how agents should interpret feedback, detect overengineering, map issues to the product spine, check traceability, reconcile Obsidian memory, and write bounded execution packets.

Use them with:

- `pnpm rb:problem:*` for raw feedback intake and translation.
- `pnpm rb:memory:*` for source-aware memory search, synth, sync plans, and trace reports.
- `pnpm rb:control:*` for next-slice selection and canonical claim tracing.

Repo truth wins over these prompts when they conflict.
