Digital logic and FPGA coursework

Visual digital-logic engineering from circuit to FPGA handoff.

RedByte is a digital logic and FPGA workbench. Build circuits, experiment live, inspect waveforms, map Basys3 resources, and prepare a Vivado-ready engineering package without hiding the proof boundary.

Open RedByte View documentation
Browser scope: E0

RedByte prepares and inspects project artifacts. Synthesis, programming, and physical board observation remain external in AMD Vivado 2024.2.

Five-stage workflow

One job at a time, from setup through submission files.

01Project

Choose a lab, starter, or saved project and steer it from one operating center.

02Design

Build the circuit on a canvas-first workbench with reusable modules.

03Simulate

Drive inputs and observe the circuit. Compare against expectations only when you choose to.

04Board & Constraints

Assign design signals to real Basys3 resources and inspect the constraints.

05Build & Export

Build and inspect the Vivado-ready handoff package.

Observed

Simulation is observe-first: a run records observed behavior even with zero checks. Expected-output checks are optional and explicit. Author them when you need formal pass/fail evidence, not before.

Visual engineering

Built for engineering work

RedByte is not a toy simulator and not a Vivado replacement. It is the browser workbench for supported digital logic design, observed simulation, Basys3 resource assignment, and package preparation.

E0

RedByte can establish that the package was generated from the current project state.

Vivado owns the hardware loop

E1 synthesis and implementation, E2 programming, and E3 physical observation remain downstream evidence. A physical Basys3 board is required for E2 programming and E3 observation.

Flow

Project -> Design -> Simulate -> Board & Constraints -> Build & Export -> Vivado

Run RedByte locally

Use the pnpm workspace and the repository-pinned Node runtime. RedByte source and maintained course docs are the truth. Generated outputs support evidence but do not expand release claims.

pnpm install pnpm dev
