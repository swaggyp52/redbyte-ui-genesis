# RedByte ECE141 Course Edition Archive and Removal Plan

Date: 2026-05-11

## Rule

Do not delete large parts of the repo from this triage branch. First preserve history, classify content, and get approval for each destructive slice.

## Phase A: Preserve Traceability

| Step | Action | Validation |
| --- | --- | --- |
| A1 | Create a tag or branch before cleanup, for example `archive/pre-course-cleanup-2026-05-11` or `archive/pre-course-cleanup`. | `git show-ref --tags` or `git branch --list archive/pre-course-cleanup`. |
| A2 | Keep the course-edition inventory docs in `docs/release/course-edition/`. | Docs validate and link from release planning. |
| A3 | Record the archive point and cleanup branch in `AI_STATE.md`. | `AI_STATE.md` change log entry. |

## Phase B: Low-Risk Generated Output Cleanup

| Candidate | Current evidence | Proposed action | Approval |
| --- | --- | --- | --- |
| `coverage/**` | Tracked coverage output detected by `git ls-files coverage`. | Remove from git, keep ignored, document regeneration command. | Required |
| Local `dist/**`, `out/**`, `playwright-report/**`, `test-results/**` | Present locally and ignored; not detected as tracked in sampled check. | Leave ignored. | Not required |
| `.redbyte/course-edition/**` | Generated by this audit. | Ignore now; do not commit artifacts. | Not required |
| `artifacts/classroom-rc-v1.zip` and built assets/logs under `artifacts/**` | Tracked release/build output detected. | Move bulky generated release artifacts to GitHub Releases or external archive; keep only manifest/proof summaries. | Required |

## Phase C: Security and Privacy Cleanup

| Candidate | Current evidence | Proposed action | Approval |
| --- | --- | --- | --- |
| `.env` | Tracked file. Redacted inspection found environment-style content. | Review content privately, rotate anything sensitive, create `.env.example`, remove `.env` from git, consider history cleanup if real secrets are found. | Required |

## Phase E: Development-Only Boundary

| Candidate | Proposed action |
| --- | --- |
| Marcus/HQ/local-agent docs and scripts | Keep in engineering repo only if they remain supported maintainer tooling. Exclude from student course zip. |
| `.claude/**`, `08 Agents + Prompts/**`, prompt vault files | Move to private/archive or label development-only. |
| Hardware bridge experiments | Keep behind maintainer QA docs; do not surface to students. |
| Business/planning vaults | Move to private/archive unless converted into maintained docs. |

## Phase F: Course Package Manifest

Create a course package manifest after Phases B through E:

| Manifest section | Contents |
| --- | --- |
| Source | App source, supporting packages, curated examples, tests. |
| Student docs | Student quick start, install/launch guide, Verify/proof guide, Vivado export guide, mapping guide, troubleshooting/reset guide. |
| Professor docs | Administration guide, evidence/grading guide, lab-machine checklist, support boundaries, release notes. |
| Exclusions | Generated outputs, private/local files, OS-era docs, Marcus/local-agent artifacts, stale planning dumps, secrets, personal logs. |

## First Safe Cleanup Slice

The first safe PR should not delete historical material. It should:

1. Add this course-edition audit folder.
2. Ignore `.redbyte/course-edition/` local audit artifacts.
3. Document tracked generated/stale/security candidates.
4. Leave `package-lock.json`, `.env`, `coverage/**`, `artifacts/**`, and stale docs untouched until approval.
