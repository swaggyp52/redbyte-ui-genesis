# v1.0.0-next-lab-ready Release Handoff

Release tag: `v1.0.0-next-lab-ready`

Release branch: `release/v1.0.0-next-lab-ready`

## Exact Command Sequence

Run from repo root:

1. `pnpm install`
2. `pnpm v1:rehearse`
3. `pnpm v1:verify -- <path-to-exported-bundle>`
4. `pnpm rc:check`

All commands must exit `0`.

## Required Artifacts

- Student project archive (`.rbproj` / `.rbproj.zip` based on active export flow)
- Student submission bundle (`.rb-lab.zip`)
- Doctor report JSON from wizard export
- Rehearsal checklist completion (`docs/rehearsal/student-setup.md`)
- Failure evidence if any failure occurred:
  - `docs/rehearsal/failure-log.md`
  - ticket copied from `docs/rehearsal/failure-ticket-template.md`

## Definition of Done

Release is done only when all are true:

1. Two clean rehearsals completed from scratch.
2. `pnpm v1:verify` passes on exported student bundle(s).
3. `pnpm rc:check` passes.
4. Any rehearsal failure was ticketed and fixed with regression coverage.

## Freeze Policy

- Freeze `v1.0.0-next-lab-ready`.
- No code changes unless triggered by real student/hardware rehearsal evidence.
- Non-evidence feature work moves to `develop` or `main` under a new milestone.

## Branch Lock (Manual GitHub Action)

Branch protection for `release/v1.0.0-next-lab-ready` must be applied in GitHub settings:

- Require pull request before merge
- Require status checks to pass
- Restrict force push and branch deletion

This step is manual and cannot be enforced from local git alone.
