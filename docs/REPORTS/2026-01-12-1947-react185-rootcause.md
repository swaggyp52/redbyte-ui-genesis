# React 185 root cause

- Wrapper: `packages/rb-utils/src/zustand.ts` (aliased from `zustand` in `vite.config.ts`, `vitest.config.ts`, and `tsconfig.json`).
- Issue: Zustand's default useSyncExternalStore wrapper evaluated `selector(api.getState())` without caching, so selectors that allocate new objects returned a different snapshot on every read, triggering React #185 and an update loop.
- Fix: cache snapshots by last state reference in `getSnapshot`/`getServerSnapshot`, returning the same snapshot when the store state object is unchanged.

Repro steps (before):
1) Run the dev server.
2) Navigate to Logic Playground.
3) Observe the React #185 warning and max update depth crash.

Repro steps (after):
1) Run the dev server.
2) Navigate to Logic Playground.
3) Confirm the warning and crash do not occur; leave idle for 30 seconds.
