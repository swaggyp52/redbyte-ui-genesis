# React 185 fix

- Change: `packages/rb-apps/src/apps/LogicPlaygroundApp.tsx:135-136` replaced the tutorial store object-literal selector with primitive selectors for `active` and `start`.
- Why it works: the previous selector returned a fresh object on every `getSnapshot` call, so Zustand's `useSyncExternalStore` saw a new snapshot each read and triggered React #185; selecting primitives returns stable references until the store changes.
