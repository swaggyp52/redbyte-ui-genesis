# Diagnostics Export Instructions

## When to use
Use this when a lab machine fails to open, submit, or grade reliably.

## Toolchain Setup export (TA mode)
1. Enter TA mode (`?ta=1`).
2. Open **Toolchain Setup**.
3. Click **Export Diagnostics Bundle**.
4. Save the generated diagnostics zip/json for triage.

## Submission Inspector export (TA mode)
1. Enter TA mode.
2. Open **Submission Inspector**.
3. Load the student bundle.
4. Click **Export Diagnostics Bundle**.

## What to attach in support handoff
- Diagnostics export file
- Failing student submission bundle
- Brief note: machine id, timestamp, and observed failure text
