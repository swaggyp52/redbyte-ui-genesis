# Third-Party Notices

This file documents all third-party dependencies used by RedByte, including their licenses and compliance status.

## License Summary

RedByte uses open-source libraries under various permissive licenses, primarily:

- **MIT**: Permissive, unrestricted use in commercial and private projects
- **Apache-2.0**: Permissive, requires copyright notice and license statement
- **BSD-2-Clause / BSD-3-Clause**: Permissive, similar to MIT with additional conditions
- **ISC**: Permissive, similar to MIT

## License Policy

The following licenses are **NOT permitted** without explicit approval:

- **AGPL-3.0-only** / **AGPL-3.0-or-later**: Requires source code disclosure for modifications
- **SSPL**: Server-side public license, requires infrastructure as service disclosure
- **GPL-3.0-only**: Viral copyleft, incompatible with closed-source software

## Dependency License Snapshot

A deterministic snapshot of all dependencies and their licenses is maintained in:

```
docs/licenses.snapshot.json
```

This snapshot is generated by the `gen-license-snapshot.mjs` script and validated by the `ui:license-audit-gate` test during every CI run.

### Regenerating the Snapshot

To regenerate the license snapshot after installing new dependencies:

```bash
node scripts/gen-license-snapshot.mjs
```

This command:
1. Scans all installed packages in `node_modules`
2. Extracts license metadata from each `package.json`
3. Generates `docs/licenses.snapshot.json` in deterministic order (sorted by name@version)
4. Fails if any `UNKNOWN` licenses are detected

## Compliance Validation

License compliance is validated by the `ui:license-audit-gate` deterministic gate:

```bash
pnpm ui:license-audit-gate
```

This gate:
1. Verifies `docs/licenses.snapshot.json` exists
2. Regenerates the snapshot and compares output (must match exactly)
3. Asserts no `UNKNOWN` licenses
4. Asserts no forbidden licenses (AGPL, SSPL, GPL-3.0-only)

The gate is wired into the standard verification chain:

```bash
pnpm verify:gates    # Includes license audit
pnpm ci:parity       # Includes license audit
```

## Adding New Dependencies

When adding a new dependency:

1. Install it normally via `pnpm add [package]` or `pnpm add -D [package]`
2. Run `node scripts/gen-license-snapshot.mjs` to update the snapshot
3. Review the added dependency in `docs/licenses.snapshot.json`
4. Commit both the `pnpm-lock.yaml` and `docs/licenses.snapshot.json` changes
5. On CI, the `ui:license-audit-gate` will validate the new snapshot

## Reviewing Licenses

To review all installed licenses:

```bash
# Deterministic snapshot (sorted by name@version)
cat docs/licenses.snapshot.json | jq '.[] | .name + "@" + .version + ": " + .license'
```
