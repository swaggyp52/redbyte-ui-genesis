# RedByte Lab Machine Requirements

## System
- Windows 10/11
- PowerShell 5.1 or 7+
- Internet Connection (for initial fetch)

## Software Prerequisites (Installed by bootstrap.ps1)
- Node.js LTS (v18+)
- PNPM (via corepack or npm)
- Chrome or Edge (latest)

## Hardware Drivers (Manual Install Required)
- Digilent Adept Runtime (for djtgcfg / hardware programming)
- FTDI Drivers (usually included with Adept or OS)
- (Optional) Vivado Lab Solutions or openFPGALoader

## Verification
Run `bootstrap.ps1` to verify software readiness.
If hardware programming fails, ensure Digilent Adept is installed:
https://digilent.com/reference/software/adept/start
