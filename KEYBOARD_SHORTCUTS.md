# Keyboard Shortcuts

Global keyboard shortcuts for RedByte OS.

## Global Shell Shortcuts

| Shortcut | Action | Context |
|----------|--------|---------|
| `Ctrl/Cmd+Space` | Open System Search | Anywhere |
| `Ctrl/Cmd+,` | Open Settings | Anywhere |
| `Ctrl/Cmd+Shift+P` | Open Command Palette | Anywhere |
| `Ctrl/Cmd+Tab` | Window Switcher | Anywhere |
| `Ctrl/Cmd+W` | Close Focused Window | Anywhere |
| `Ctrl/Cmd+M` | Minimize Focused Window | Anywhere |
| `Ctrl/Cmd+Alt+Arrow` | Snap Focused Window | Anywhere |
| `Ctrl/Cmd+Alt+C` | Center Focused Window | Anywhere |

## Windowing

| Shortcut | Action | Context |
|----------|--------|---------|
| `Shift + Drag (edge)` | Snap Preview (Manual Snap Assist) | Dragging windows |

## App-Specific Shortcuts

### Logic Playground

| Shortcut | Action | Notes |
|----------|--------|-------|
| `Ctrl/Cmd+Z` | Undo | Reverts last circuit change (up to 50 steps) |
| `Ctrl/Cmd+Y` or `Ctrl/Cmd+Shift+Z` | Redo | Reapplies undone change |
| `Ctrl/Cmd+O` | Open Circuit | Shows file picker with saved circuits |
| `Ctrl/Cmd+S` | Save Circuit | Saves to current file or shows Save As modal |
| `Ctrl/Cmd+Shift+S` | Save As | Creates new file with custom name |
| `Ctrl/Cmd+Shift+C` | Share Circuit | Copies compressed URL to clipboard |
| `Ctrl/Cmd+1..6` | Switch Right Dock Tabs | 1=Inspector, 2=Health, 3=Learn, 4=Probes, 5=Record, 6=Chips |
| `Shift+P` | Open Probes Tab | Opens Right Dock in Probes view |
| `?` | Show Keyboard Shortcuts | Toggles the shortcuts overlay |

### Files App

| Shortcut | Action | Notes |
|----------|--------|-------|
| `Ctrl/Cmd+Shift+N` | New Folder | Opens folder creation modal |
| `F2` | Rename | Renames selected file/folder |
| `Delete` | Delete | Deletes selected file/folder |
