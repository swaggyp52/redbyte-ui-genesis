## Scope (Must-Have)

### 1. Import LogicCanvas into LabApp
```tsx
import LogicCanvas from '@redbyte/rb-logic-view';
```

Requirements:
- LogicCanvas must accept `circuit: Circuit` and `onCircuitChange: (circuit: Circuit) => void`
- No modifications to LogicCanvas API (use as-is)

### 2. Wire Session Store → LogicCanvas
- On mount: read `sessionState.currentCircuit` (JSON string)
- Parse to Circuit object (safe parse, fallback to empty circuit)
- Pass to LogicCanvas as initial state

### 3. Wire LogicCanvas → Session Store
- On every LogicCanvas change, call `sessionStore.setCircuit(JSON.stringify(circuit))`
- Debounce to 500ms to avoid excessive saves
- No need for explicit save button (auto-persist)

### 4. Export capsule includes circuit
- The export already references `sessionState.currentCircuit`
- Verify circuit is in exported CapsuleV1
- No changes needed to export logic

### 5. Reload restores circuit
- On page refresh, LabApp loads session from localStorage (already exists)
- Render LogicCanvas with restored circuit
- Acceptance: build circuit → refresh → circuit intact

## Implementation Pattern

```tsx
// Pseudocode (exact implementation in PR)

import LogicCanvas from '@redbyte/rb-logic-view';
import { debounce } from 'lodash'; // or write simple debounce

// In component:
const [circuit, setCircuit] = useState<Circuit | null>(null);

// On mount: parse and restore
useEffect(() => {
  if (sessionState?.currentCircuit) {
    try {
      const parsed = JSON.parse(sessionState.currentCircuit);
      setCircuit(parsed);
    } catch (e) {
      console.warn('Failed to parse circuit:', e);
      setCircuit(null); // fallback to empty
    }
  }
}, [sessionState?.currentCircuit]);

// On circuit change: debounce and persist
const handleCircuitChange = debounce((newCircuit: Circuit) => {
  setCircuit(newCircuit);
  sessionStore.getState().setCircuit(JSON.stringify(newCircuit));
}, 500);

// Render LogicCanvas in center panel
<div style={{ gridColumn: '2', gridRow: '2', ... }}>
  {circuit ? (
    <LogicCanvas 
      circuit={circuit}
      onCircuitChange={handleCircuitChange}
    />
  ) : (
    <div>Loading circuit...</div>
  )}
</div>
```
