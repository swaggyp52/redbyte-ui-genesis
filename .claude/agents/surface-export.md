# surface-export agent

## Domain Ownership
This agent owns the Export surface of the RedByte IDE — VHDL/Verilog generation, XDC constraints, export artifact validation, and ZIP download.

## Primary Files
- `packages/rb-apps/src/apps/ide/surfaces/ExportSurface.tsx` — main export surface component
- `packages/rb-apps/src/export/projectFormat.ts` — `RBProject` schema, encode/decode
- `packages/rb-apps/src/export/netlistExport.ts` — circuit IR → netlist
- `packages/rb-apps/src/export/vhdlExport.ts` — netlist → VHDL text
- `packages/rb-apps/src/apps/ide/viewmodels/buildExportViewModel.ts` — derives export artifacts + diagnostics from project state
- `packages/rb-apps/src/fpga/boards/basys3/basys3Bundle.ts` — `buildVhdlTopLevelBindings()` — builds port maps for Basys3

## ExportSurface Props
```typescript
interface ExportSurfaceProps {
  project: RBProject;
  verifyResult?: ProjectHealthVerifyResult;
  verifyLastRun?: RuntimeVerifyRun;
  dirtySinceVerify: boolean;
  determinismHash: string;
  onExportResult: (result: ProjectHealthExportResult) => void;
  onDiagnosticAction: (diagnostic: IdeDiagnostic) => void;
  onOpenVerify: () => void;
  example?: IdeExampleDefinition | null;
  onGoToHardware?: () => void;
  onGoToProject?: () => void;
}
```

## Export Artifacts
`buildExportViewModel(project, verifyLastRun)` returns:
```typescript
{
  artifacts: Array<{
    path: string;      // e.g. 'top.vhd', 'top.xdc', 'EXPECTED_IO.json', 'vectors.json'
    content: string;   // text content
    language?: string; // 'vhdl' | 'verilog' | 'xdc' | 'json'
  }>;
  diagnostics: IdeDiagnostic[];
  readyForExport: boolean;
  zipFilename: string;
}
```

## Key Artifacts
| Path | Content |
|------|---------|
| `top.vhd` | VHDL source generated by `vhdlFromNetlist()` |
| `top.xdc` | Xilinx constraint file with clock and I/O pins |
| `vectors.json` | Test vector JSON export |
| `EXPECTED_IO.json` | Signal tick-by-tick expected outputs for hardware bringup |
| `*.rbproj.json` | Full project snapshot JSON |

## VHDL Generation Pipeline
```
circuit IR
  → netlistFromCircuit()   (packages/rb-apps/src/export/netlistExport.ts)
  → vhdlFromNetlist()      (packages/rb-apps/src/export/vhdlExport.ts)
  → buildVhdlTopLevelBindings()  (basys3Bundle.ts — adds entity port map)
  → hdlText (stored in exportProject.hdl.sources[0].text)
```

## XDC Constraints
Built by `buildConstraintText(ioRows)` in `IdeApp.tsx`. Generates:
```xdc
create_clock -name sys_clk -period 10.000 [get_ports clk]
set_property PACKAGE_PIN W5 [get_ports clk]
```

## Export Checklist
ExportSurface shows a checklist of required conditions before export:
1. Circuit has gates
2. I/O mapping is complete (all required pins assigned)
3. Verification passed (no stale result)
4. No compiler errors

## Export as ZIP
When user clicks "Download ZIP":
1. All artifacts are collected into an in-memory ZIP archive
2. Blob URL is created and `<a href>` click is triggered for download
3. `onExportResult` callback is called with export metadata

## IdeDiagnostic for Export
Diagnostics for export issues:
- `severity: 'error'` — blocking (no export allowed)
- `severity: 'warn'` — non-blocking warning
- Each diagnostic has `action: { mode, payload }` used by `onDiagnosticAction` to navigate to the relevant surface

## Common Tasks
- **Fix VHDL generation error**: Trace through `netlistFromCircuit` → `vhdlFromNetlist` → check for unsupported node types
- **Add new artifact to ZIP**: Add entry to `buildExportViewModel` artifacts array
- **Fix XDC constraints**: Edit `buildConstraintText` in IdeApp.tsx
- **Fix export checklist item**: Edit `buildExportViewModel` readiness checks
- **Debug missing port in VHDL**: Check `buildVhdlTopLevelBindings` port map logic in basys3Bundle.ts
