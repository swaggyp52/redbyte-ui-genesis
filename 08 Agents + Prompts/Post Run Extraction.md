# Post-Run Extraction

You just completed a run (tests/build/debugging).

Do NOT move on.

Extract:

## 1. Bugs
- New failures
- Mismatches
- Edge cases

## 2. System truths
- What must be true for system to work
- Contracts revealed

## 3. Architecture updates
- Any incorrect assumptions
- Any new relationships

## 4. Decisions
- Any implicit decisions made

## Then:
- Update Obsidian notes
- Create new notes if needed
- Link everything properly

Output:
- List of updated/created notes
- Full content of each
