# RedByte linked representations

Use the runtime/project as authority and add bounded adapters over structural IR. A committed inspection identifies project/revision, live or recording, case/tick/evaluation phase, instance ID path, node/port/net and bit. Labels are presentation, never identity. Capture provenance during elaboration; repeated definitions and same-named instances remain distinct. Hover previews and pins do not replace committed selection.

Expose select/reveal, follow actual driver/load, enter instance and seek moment consistently. Avoid feedback loops, stale async responses and unrelated camera resets. Retained recordings use their retained topology; an older circuit never becomes current proof.

Observe actual execution at evaluation boundaries. Capture actual inputs read, their drivers, previous/result outputs and state. Topological order is not a transition trace. Keep disabled instrumentation off the hot path, bound enabled traces and expose truncation/cancellation. Playback reads captures and never re-evaluates state. Independent evaluations are not serial physical causality; logical order is not nanosecond delay, hazards or glitches. Changed inputs may leave outputs unchanged.

Derive bounded read-only Boolean expressions from supported combinational cones with node/port references. Stop at registers, feedback, unsupported primitives and size limits. Terms select the same gates and use values from the chosen evaluation. Expressions never author expected answers.

Generate HDL correspondence from deterministic emitter metadata for the same revision, including instance paths and assignment/port spans. Never match arbitrary global label text or manufacture source correspondence for imported behavioral HDL or an old recording against current generated code. Board inspection follows real mapping and simulated recorded values; it never drives an output or claims physical observation.

Legacy recordings remain readable. If execution is reproduced to obtain a trace, label it reproduced, bind snapshot and engine contract, and check published boundaries against the retained samples before displaying it. On/off differential tests must agree on published values, state and verdict. Cover fan-out/reconvergence, unchanged output, clock/reset, repeated instances, unknown/unrecorded values, invalid feedback and trace bounds. Isolate scheduler defects with minimal regressions and version the execution contract.
